## How to Run

1. Clone or download the repository.
2. Open the folder in Jupyter Notebook, JupyterLab, or VS Code.
3. Install the required packages if they are not already installed:

   ```bash
   pip install pandas numpy matplotlib plotly scipy jupyter
   ```

4. Open the relevant `.ipynb` notebook and run the cells in order.
5. Keep each CSV dataset in the expected location relative to its notebook so the data-loading cells work.
